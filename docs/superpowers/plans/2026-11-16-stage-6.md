# Tahap 6 — Panel staf dan moderasi

Acuan: T-401–T-405, planning/07 dan planning/11. Permintaan melanjutkan tahap mengotorisasi eksekusi rencana yang telah tersedia.

- [x] T-401: password bcrypt + TOTP, sesi staf terpisah dari JWT perangkat, CSRF, kuota login, seed CLI. Role kanonik MOD/ADMIN.
- [x] T-402: antrean, SLA, detail, keputusan beralasan dengan CAS version, koreksi reputasi/sync, audit append-only dan pemulihan operasi gagal.
- [x] T-403: kurasi verified/emergency/channels, validasi sumber/tanggal, batch CSV/JSON memakai parser/importer yang tersedia, audit dan sync.
- [x] T-404: HTML/JS/CSS tertanam di backend, login shell tanpa data privat, antrean/detail/keputusan, lookup nomor, kurasi/import, audit dan tombol ekspor.
- [x] T-405: ekspor JSON/CSV melalui proyeksi field aman, khusus ADMIN, proteksi formula CSV.
- [x] Verifikasi: TDD, go vet, seluruh suite Go dan MongoDB terisolasi, browser smoke, review lintas tugas; perbarui checklist/evidence.

Keputusan implementasi: panel memakai origin backend yang sama dan aset lokal. Halaman login boleh diakses tanpa sesi; seluruh API data admin memerlukan staf. Cookie HttpOnly/SameSiteStrict; Secure pada produksi. Tidak membuat akun staf atau menulis database kerja selama pengembangan. Pengujian menggunakan direktori/database temporer terisolasi.
