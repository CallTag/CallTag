# Rencana implementasi Tahap 4B

Acuan: CHECKLIST-PELAKSANAAN Tahap 4B, T-207 sampai T-210. Permintaan pengguna melanjutkan tahap tersebut menjadi otorisasi eksekusi spesifikasi yang tersedia.

- [x] T-207: model dan penyimpanan verified_numbers, sumber resmi bertanggal, lookup hanya untuk entri aktif belum kedaluwarsa; uji expiry dan metadata.
- [x] T-208: normalisasi internasional, tabel prefix operator/PSTN/negara dan sumber; uji longest prefix serta UNKNOWN.
- [x] T-209: parser CSV/JSON, CLI dry-run dan impor idempoten, validasi/provenans, jurnal sinkronisasi; uji parser dan penyimpanan.
- [x] T-210: INFO_TAG berbobot nol, saringan PII pada tag dan komentar; uji tag tersimpan tanpa kontribusi skor atau kuorum bahaya.
- [x] Integrasi: go vet ./... dan go test -v ./..., tinjau diff baru dan perbarui checklist beserta batas bukti.

Implementasi mempertahankan perubahan lokal yang sudah ada. Dataset eksternal tidak menjadi blacklist resmi; prefix memberi konteks jaringan/alokasi, bukan kepastian pemilik atau penipuan. Tidak mengimpor tuduhan publik ke database kerja selama pengembangan.
