## Cakupan implementasi

- T-207: koleksi `verified_numbers`, indeks unik, validasi dokumen MongoDB, 18 nomor layanan resmi, metadata sumber dan tanggal verifikasi, pelindung hanya untuk entri aktif belum kedaluwarsa. Seed tidak memperpanjang tanggal atau menimpa pencabutan staf.

- T-209: CLI CSV/JSON `verified|scam|tag_context`, validasi sebelum penulisan, `-dry-run` tanpa koneksi database, deduplikasi, sumber eksternal terpisah dan jurnal sinkronisasi. Fixture dua entri CallShield dipatok ke commit dan disertai lisensi MIT serta atribusi.
- T-210: `INFO_TAG` berbobot nol, disimpan sebagai laporan/tag tanpa menambah skor atau kuorum bahaya; kategori gangguan tetap dominan pada profil campuran. Tag dan komentar disaring dari pola PII.

- Integrasi tampilan Android/website, panel kurasi admin dan demo panggilan berada pada tahap berikutnya.

## Bukti pengujian

Semua pemeriksaan berikut selesai dengan exit code 0:

```bash
cd backend
go vet ./...
CALLTAG_TEST_MONGO_URI=mongodb://127.0.0.1:28019 go test -v ./...
go run ./cmd/importdataset -file seeds/verified_numbers_seed.json -kind verified -source OFFICIAL_DOMAIN_REVIEW -dry-run
go run ./cmd/importdataset -file internal/dataset/testdata/callshield_sample.json -kind scam -source EXTERNAL_OPEN_LIST -dry-run
git diff --check
```

Dry-run pertama memvalidasi 18 entri dan kedua 2 entri; keduanya menulis 0 dokumen. Tidak ada test yang dilewati pada suite MongoDB ini. Pengujian mencakup penyimpanan laporan aplikasi sebelumnya, parser/importer, fixture MIT, netralitas INFO_TAG dalam memory dan MongoDB, redaksi identitas pelapor, status aktif/kedaluwarsa/dicabut, serta pemulihan kegagalan agregasi dan jurnal verifikasi.
